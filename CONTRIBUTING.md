# Contributing to Awesome AI Agents

Thank you for your interest in contributing to **Awesome AI Agents**! Your contributions help make this project better for everyone.

## How to Contribute

### 1. Submitting a New Entry
If you have a framework, tool, or resource that should be added to this list, follow these steps:

- Ensure the project is **actively maintained** (updated within the last 6 months) and relevant to AI agents.
- Check that the project is not already listed.
- Show some **use beyond the author** — stars, forks, dependents, package downloads, or coverage elsewhere. Brand-new projects with no outside signal yet are usually too early to list; submit them as an [emerging project](#2-submitting-an-emerging-project) instead.
- Open a Pull Request (PR) with the following format:

  ```markdown
  | [Project Name](project-url) | ![](https://img.shields.io/github/stars/owner/repo) | Short description of the project |
  ```

- Add it to the correct section in `README.md`.

Once your entry is merged, you can add this badge to your project's README:

[![Featured in Awesome AI Agents](https://img.shields.io/badge/Featured_in-Awesome_AI_Agents-2ea44f)](https://github.com/NipunaRanasinghe/awesome-ai-agents)

```markdown
[![Featured in Awesome AI Agents](https://img.shields.io/badge/Featured_in-Awesome_AI_Agents-2ea44f)](https://github.com/NipunaRanasinghe/awesome-ai-agents)
```

### 2. Submitting an Emerging Project
If your project is relevant to AI agents but does not yet show use beyond the author, you can add it to [`EMERGING.md`](EMERGING.md) instead. An emerging project must:

- Be relevant to AI agents, with working code and a README that explains what it does.
- Have an open-source license.
- Be submitted by its owner or a maintainer.
- Be at least 30 days old, with a commit in the last 30 days.

Add a row to the table in `EMERGING.md`, with the main-list section it belongs in and the current month:

```markdown
| [Project Name](https://github.com/owner/repo) | ![](https://img.shields.io/github/stars/owner/repo) | Coding Agents | 2026-10 | Short description of the project |
```

A monthly check opens an issue listing emerging entries to move or remove:

- **Moved to the main list** when the repo reaches 50 stars. You can also open a PR to move it earlier if you can show other use, such as 1,000+ monthly package downloads or contributors from outside your team.
- **Removed** when nothing has been pushed to the repo for 3 months, or is still below the bar 6 months after it was added. You can submit it again later.

Once your entry is merged, you can add this badge to your project's README:

[![Emerging in Awesome AI Agents](https://img.shields.io/badge/Emerging_in-Awesome_AI_Agents-0969da)](https://github.com/NipunaRanasinghe/awesome-ai-agents/blob/main/EMERGING.md)

```markdown
[![Emerging in Awesome AI Agents](https://img.shields.io/badge/Emerging_in-Awesome_AI_Agents-0969da)](https://github.com/NipunaRanasinghe/awesome-ai-agents/blob/main/EMERGING.md)
```

### 3. Fixing Issues or Broken Links
If you find broken links or outdated information, please:

- Open an issue detailing the problem.
- Submit a PR with the correct information.

### 4. Improving Documentation
If you can improve the clarity, formatting, or structure of the README or other documents, contributions are welcome.

## Contribution Guidelines

- Keep descriptions **concise** and **informative**.
- Use **proper Markdown formatting**.
- Follow the **existing structure** of the list.
- Ensure links are **publicly accessible**.
- Avoid adding duplicate resources.
- Be **respectful and constructive** in discussions.

## How to Submit a Pull Request

1. Fork the repository.
2. Create a new branch: `git checkout -b feature-name`.
3. Commit your changes: `git commit -m "Add new AI agent tool"`.
4. Push to your branch: `git push origin feature-name`.
5. Open a Pull Request (PR) and describe your changes.
